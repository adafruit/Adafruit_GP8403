Initialize the GP8403 in a known, safe state.

The device is probed, placed in the 0 V to 5 V range, and both channels are set to zero. The GP8403 has no readable identification register.

Parameters
address7-bit I2C address.
wireI2C interface to use.
Returns
true if the probe and all initialization writes succeeded.

bool Adafruit_GP8403::saveToNVM ( uint16_t  sdaPin,
uint16_t  sclPin 
)

Persist the current GP8403 output voltage data to NVM.

The datasheet specifies a nonstandard bus waveform rather than an ordinary I2C register write. This implementation uses portable open-drain GPIO signaling on the supplied SDA and SCL pins. The caller must release the I2C peripheral before this call and restore its configuration afterward.

A true return value confirms that the waveform was emitted and the documented entry and exit acknowledgments were observed. It cannot verify persistence without a power cycle.

Parameters
sdaPinSDA pin used by the configured Wire interface.
sclPinSCL pin used by the configured Wire interface.
Returns
true if the complete waveform and acknowledged bytes succeeded; false if uninitialized, unsupported, or not acknowledged.
